An original 5v5 round-based tactical FPS set in a desert solar farm at golden hour. You are an attacker: plant the bomb at **Site A** (control building) or **Site B** (panel array), or eliminate the defending bots. First to 8 rounds wins the match. Buy weapons, armor, and grenades between rounds; bots route, hold sites, and react to sight and sound.

## How to play

- **WASD** move, **mouse** look (click to lock pointer), **Shift** sprint, **Ctrl/C** crouch, **Space** jump
- **Left click** fire, **R** reload, **1–5** switch weapon, **B** buy menu, **E** plant/defuse the bomb (hold), **G** throw grenade, **Q** smoke
- Headshots deal double damage. Firing on the move spreads your shots — stop and aim for accuracy.
- Kill: $300. Round win: $3,250. Round loss: $1,900 + loss streak bonus.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/game/ in a browser.
